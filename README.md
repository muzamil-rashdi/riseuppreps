# RiseUp Preps

Full-stack platform for a college-prep academy, covering student performance tracking, sponsor donations, attendance, and messaging.

## Product areas

- Student and academic performance records
- Attendance tracking
- Sponsor and donation workflows
- Messaging between platform users
- Role-aware access across the application

## Architecture

React frontend -> Express API -> Prisma ORM -> PostgreSQL, with Docker-based service delivery. The repository is organized into frontend, backend, and nginx layers.

## Technology

React, Express, Prisma, PostgreSQL, Docker, Nginx, and JavaScript/TypeScript.

## Run locally

Review the environment examples first, then start the development stack with docker compose up --build. See the project documentation and testing guide for the exact environment variables and service ports.

## Portfolio context

This personal project demonstrates end-to-end product delivery: schema design, API development, frontend integration, deployment configuration, and documentation.
